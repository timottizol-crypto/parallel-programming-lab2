## Описание

Реализация программы умножения квадратных матриц на C++ с использованием технологии OpenMP. Проведена серия экспериментов с разным числом потоков (1, 2, 3, 4, 6, 7, 8) и разными размерами матриц (200–1600).

## Структура

- `index.html` — отчёт с таблицами и графиками
- `cpp/main.cpp` — программа на C++ с OpenMP
- `python/generate.py` — генератор матриц
- `python/verify.py` — верификация через NumPy
- `python/run_experiments.py` — автоматический прогон замеров
- `python/plot.py` — построение графиков
- `img/` — графики (PNG)
- `results.txt` — данные замеров

## Как запустить

```bash
# Сборка C++
cd cpp
g++ -O2 -fopenmp -o ../data/matrix.exe main.cpp

# Прогон экспериментов
cd ../python
python run_experiments.py

# Построение графиков
python plot.py
